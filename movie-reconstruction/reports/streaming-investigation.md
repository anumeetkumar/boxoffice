It initialized port 7000. Bigg Boss Season 20 Episode 1 was opened through the original app's catalog. It buffered and then failed with the same HttpDataSourceException / unexpected end of stream / EOF before response headers (device log at 14:37:35). The phone comparison therefore also reproduces the error in the untouched original, under the conditions at test time. This does not dispute that it worked earlier, and does not establish the precise upstream/network cause.

The original SDK's read-only `/control?msg=download_info` response was HTTP 200 with an empty array. No explicit download task was created in this fresh test installation. The test application's external files directory occupied about 67 MiB while the stream was buffering; this does not establish that a whole-video download was requested. Evidence: phone-original-comparison-log.txt, phone-original-episode-check.png, phone-original-sdk-download-info.json, phone-original-sdk-info-headers.txt.

The rebuilt APK was selected for restoration after this approved temporary comparison; restoration status is recorded separately in streaming-phone-status.json. No device security or connectivity settings were changed. The temporary local ADB forwards and owned emulator were closed. No speculative buffer or download-mode patch has been shipped for this issue. The native Java/Kotlin APK has no React Native/Expo live-reload workflow.
